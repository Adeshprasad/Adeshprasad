### 💼 CareerForge — Full-Stack Job Application Tracker

<p>
  <a href="https://career-forge-teal.vercel.app/">
    <img src="https://img.shields.io/badge/Live_Demo-Visit_App-00C7B7?style=for-the-badge&logo=vercel&logoColor=white" alt="Live Demo"/>
  </a>
  <a href="https://github.com/Adeshprasad/careerForge">
    <img src="https://img.shields.io/badge/Source_Code-GitHub-181717?style=for-the-badge&logo=github&logoColor=white" alt="Source Code"/>
  </a>
</p>

A full-stack MERN application designed to manage job applications throughout the recruitment process.

- Developed **13 REST API endpoints** across five feature areas.
- Implemented JWT authentication and role-based access control.
- Built application tracking with filtering, sorting, pagination, and status history.
- Added interview tracking, follow-up reminders, analytics, and PDF resume uploads with server-side validation.
- Deployed the frontend on Vercel and backend on Render, using MongoDB Atlas.

**Tech:** React · Node.js · Express.js · MongoDB · JWT · Multer

### 😴 Wearable Data to Sleep Quality Prediction

[![Repository](https://img.shields.io/badge/Source_Code-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/Adeshprasad/WearableDataToSleepQualityPrediction)

An end-to-end time-series machine learning pipeline that predicts sleep quality using wearable-device data.

- Worked with features such as step count, heart rate, and screen time.
- Engineered lag features and rolling averages.
- Used chronological train/test splitting to prevent data leakage.
- Compared Linear Regression and Random Forest using MAE and R².

**Tech:** Python · pandas · NumPy · scikit-learn
